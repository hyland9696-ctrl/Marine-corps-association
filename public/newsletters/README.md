# Scuttlebutt archive

Drop each issue's PDF in this folder and rebuild. The Scuttlebutt page lists
every PDF here, newest first, grouped by year, and embeds the newest one.

Filenames must start with the issue month in the detachment's own `MM-YY`
form, for example:

    12-25 Scuttlebutt FINAL.pdf
    01-26 Scuttlebutt.pdf

`YYYY-MM` also works (`2026-01 Scuttlebutt.pdf`). Anything else is ignored.
